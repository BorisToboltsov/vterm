# ADR 0010 — Дизайн-система держится гейтами, а не соглашением

**Статус:** принято (Фазы 42 · 43 · 44 · 44.10).

## Контекст

Дизайн-система была зафиксирована в Фазе 7 как соглашение. К Фазе 43 в коде накопилось: 47
сырых палитровых классов Tailwind в 19 файлах, 385 `text-white`, 328 литеральных размеров
шрифта в 62 файлах, литеральные длительности во всех Svelte-переходах. Каждое нарушение
проходило ревью, потому что **по отдельности выглядело верно** — расхождение видно только
когда два элемента оказываются рядом, или только на светлой теме, или только у пользователя,
попросившего ОС не двигать интерфейс.

Ключевое наблюдение: разработчик на дефолтной тёмной теме и без `prefers-reduced-motion`
физически не может заметить эти дефекты.

## Решение

Каждое правило дизайн-системы, которое можно проверить статически, **закреплено гейтом**:

| Гейт | Что держит |
|------|------------|
| `statuscolor` | Семантический цвет — из токенов темы (`ok`/`warn`/`bad`), не из палитры Tailwind; `text-white`/`text-black` тоже |
| `typography` | Размеры — из шкалы, не `text-[Npx]`; в шкале нет line-height companion-ов |
| `motion` | Длительности переходов — из `motion.ts`, не литералы |
| `overlay` | У каждого оверлея явный `z-index` |
| `passwordinput` | Нет сырых `<input type="password">` |

Отдельно зафиксировано, **почему** гейт, а не правило в документе: общий
`prefers-reduced-motion`-guard в CSS выглядит исчерпывающим, но Svelte 5 крутит переходы
через WAAPI, которым стили не управляют — то есть до Фазы 42 **все** переходы шли на полную
длительность у пользователя, попросившего их выключить, и на месте вызова это неотличимо от
корректного кода.

## Последствия

- Визуальный язык нельзя сдвинуть попутно с другой задачей — прогон падает.
- Гейт проверяется **на живом нарушении**, а не только на зелёном коде: первая версия гейта
  вкладок падала на собственном комментарии в документации модуля, первая версия
  `terminput`-гейта молча пропускала ровно то, ради чего писалась.
- Новый визуальный контракт добавляется вместе с гейтом; иначе он продержится до первого
  разработчика, который его не читал.
