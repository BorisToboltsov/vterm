# ADR 0008 — Markdown как недоверенный вход: две независимые защиты

**Статус:** принято (Фазы 44.3 – 44.6).

## Контекст

[markdown.ts](../../src/lib/markdown.ts) писался под один вызов — встроенную инструкцию
приложения, — и его шапка это фиксировала: «never user content». К Фазе 44 вызовов стало
пять, и четыре кормят его тем, что мы не контролируем: ответ LLM, AI-план, **любой `.md`,
открытый по SFTP**, и заметки. Экранирования здесь принципиально не хватает:
`[x](javascript:…)` не вставляет разметку — он становится `href` якоря, который мы строим
сами. У окна нет адресной строки, а WebView имеет `invoke()` ко всем командам Tauri.

## Решение

**Две половины, каждая проверяет схему независимо** — чтобы ни одна не осталась
единственным, что стоит между `javascript:` и `invoke()`:

1. Цель ссылки проходит allowlist схем `safeUrl` (`http`/`https`/`mailto` + относительные).
   Отклонённая ссылка рисуется **текстом**, а не мёртвым `href="#"`.
2. Любой `{@html}` с markdown **обязан** висеть на элементе с `use:mdLinks`, который
   безусловно давит `preventDefault()` и отдаёт http(s) системному браузеру.

Производные решения того же периода:

- **Картинки — только `data:` из байтов, которые прочитали мы сами** (`mdimage.ts`, тем же
  транспортом, которым пришёл документ). Удалённый `http(s)` — никогда: `<img>` это GET,
  поэтому враждебный `.md` узнал бы, когда и откуда его открыли. Отказ рисуется
  плейсхолдером с alt-текстом, а не значком битой картинки.
- **Статический бейдж shields.io — исключение по строгому правилу**: URL `…/badge/…`
  полностью описывает картинку, поэтому она **вычисляется**, а не загружается. Динамические
  эндпоинты остаются плейсхолдером.
- **Raw-HTML — санитайзер по allowlist** (`htmlsan.ts`), а не отмена экранирования: список
  тегов, у каждого свой список атрибутов, каждое значение перепроверяется. Биас на drop.
  Включается opt-in и только в превью редактора.

## Последствия

- Гейт `mdlink.guard` проверяет **поэлементно и по исходнику без комментариев**: первая,
  файловая версия гейта прошла на файле с удалённым экшеном, потому что рядом лежал
  комментарий со словами «use:mdLinks».
- Новый вызов `renderMarkdown` подключается сразу с экшеном; не-markdown `{@html}` — записью
  в `EXEMPT` с причиной.
- Расширять allowlist «на всякий случай» нельзя — новый тег или атрибут добавляется с тестом
  на границу.
- Это ровно тот класс дрейфа, который не виден на отдельном коммите: каждый из четырёх
  вызовов по месту выглядел нормально, неверным был только их набор.
