# ADR 0077 — Проект в панели файлов: роли, Git, полоса команд

**Статус:** принято (готовится). Расширяет полосу Ansible и Terraform из [ADR 0071](0071-scenarios.md).

## Контекст

IDE, открыв проект, размечает его: JetBrains — папки кода, тестов и исключённое (приглушено), VS Code —
значки по имени и типу, Git-буквы, приглушённое из `.gitignore`. SFTP-клиенты показывают голый список.
У vterm была полоса Ansible/Terraform и цвета как у `ls`. Владелец посмотрел три варианта подсветки
(тихо, роли, как в IDE) и выбрал «как в IDE»; затем — действия полосы для всех типов (рендер на 11 типов).

## Решение

**1. Модель по именам, без чтения** (`projectmap.ts`). `projectOf(путь, листинг)` — тип папки по самому
сильному признаку: Ansible (`ansible.cfg`, `group_vars`/`roles` с YAML), Terraform (`*.tf`, lock), Helm
(`Chart.yaml`), Kustomize, Rust, Go, Python, Node, Compose, nginx (`/etc/nginx` или `nginx.conf`), systemd
(каталоги юнитов или ≥2 юнита), Docker, манифесты k8s. `roleOf` — роль строки: манифест, lock, код,
тесты, точка входа, служебное (сделано инструментом), секреты, переменные, инвентарь, задачи, юнит,
таймер, включённое. Вне проекта роль тоже есть (`.env` — секрет, `README` — документ).

**2. Вид «как в IDE»** (`rowLook`): значок роли или языка файла (Python, Rust, Go, Node, Terraform,
Dockerfile, Markdown), тон из токенов темы (`accent`, `ok`, `warn`, `muted`, `rail-2` — переменные),
манифест — полужирным, секрет — именем в тоне предупреждения, служебное — приглушено с меткой.
«Скрыть служебное» — в меню «Вид», по умолчанию выключено (`settings.sftp.hideGenerated`); скрытое
названо строкой «Служебное скрыто: N · показать». Значки — в реестре `icons.ts`, в том же стиле.

**3. Git-статус.** Один `git status --porcelain=v2 --branch -z --ignored -- .` и `rev-parse --show-prefix`
на листинг, через драйвер Git (его политика), одно чтение в полёте, только пока панель на экране (`gitlisting.ts`).
Буква у строки: M, A, D, R, U (не отслеживается), C (конфликт), точка — изменения внутри; игнорируемое
приглушено. Ветка, ↑↓ и число изменений — на полосе.

**4. Полоса команд** (`projectactions.ts`, `ProjectStrip`). Кнопка **печатает команду в терминал
соединения** — её видно, её можно прервать, бэкенд её не исполняет; если терминал не в папке проекта —
сначала `cd`. Команда — argv, закавыченный под оболочку вкладки, или готовые строки по оболочкам
(`. .venv/bin/activate` / `Activate.ps1`); команды без формы для оболочки не печатаются. По типам:
Python (окружение, тесты, зависимости, линт, типы; менеджер по lock-файлу — uv, poetry, pdm, pipenv, pip),
Rust, Go, Node (установка, скрипты), Compose (статус, поднять, логи, образы, сборка, проверка, `down`),
Kustomize и манифесты (показать, разница, применить, проверка на кластере), Helm (линт, шаблон,
установка формой: релиз, namespace, values), nginx (`nginx -t`, перезагрузка только после успешной
проверки), systemd (перечитать юниты). Ansible и Terraform — как в ADR 0071, плюс роли и коллекции,
граф инвентаря, `init`/`validate`. «Задачи ▾» — цели Makefile, рецепты justfile, задачи Taskfile,
скрипты `package.json` (одно чтение). «↻» повторяет последнюю команду папки. У юнита systemd и у
сайта nginx — команды в меню строки.

**5. Что спрашивает.** «Всегда» — что останавливает или заменяет (`down`, `apply`, `helm upgrade`,
`restart`, `disable --now`, выключение сайта); «на проде» — что запускает или перезагружает (`up -d`,
перезагрузка nginx, `enable --now`, `daemon-reload`) и любая задача (что она делает, знает только
Makefile). Вопрос — с командой целиком, папкой и контекстом kubectl, на проде — красный.

**6. Контекст kubectl и helm** — из панели k8s (`dockState.k8sScope`), явно в argv (`--context`,
`--kube-context`): `apply` не уйдёт в кластер, которого человек не видел.

**7. Факты** — одно чтение манифеста (`manifestFacts`): имя и версия, edition, `requires-python`, модуль
Go, `engines.node`, appVersion и зависимости чарта, сервисы Compose.

## Отвергнуто

- **Исполнять команды бэкендом** — человек не видел бы вывода и не мог бы ответить на вопрос команды.
- **Чтение файлов для определения типа** — сотни чтений на каждый переход по папкам.
- **Java, PHP, Ruby, .NET** — позже, сначала распознавание.

## Последствия

- Адаптер панели получил `gitStatus` и `readText`; полоса не рисует меню и диалогов (она в `@container`,
  их рисует панель).
- Гейт `editorwork.guard`: полоса без меню и диалогов, ничто в `files/` не пишет в терминал.
