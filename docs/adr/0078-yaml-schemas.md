# ADR 0078 — YAML по JSON Schema без сети

**Статус:** принято (готовится).

## Контекст

Опечатка в ключе Compose, `replicas: "3"` в Deployment, лишний уровень в workflow — линтер на сервере
скажет о них по кнопке, если установлен. VS Code с yaml-language-server проверяет по схемам на лету, но
скачивает их из SchemaStore. vterm в рантайме в сеть не ходит (принцип 6).

## Решение

**1. Схемы — с приложением** (`src/lib/editor/schemas/`, NOTICE.md): Compose, GitHub Actions (workflow и
action), GitLab CI, kustomization, `Chart.yaml` и 26 частых видов Kubernetes `v1.31.0`. Скачивает их
`scripts/schemas.mjs` при разработке: описания укорочены, у k8s оставлены определения нужных видов,
объекты строгие (`additionalProperties: false` — опечатка видна), `int-or-string` — строка или число.
Всего около 560 КБ, каждая грузится при первой проверке своего файла. Только MIT и Apache-2.0:
схемы ansible-lint — GPL-3.0, их нет; Ansible проверяет `ansible-lint` и языковой сервер.

**2. Какая схема** (`schemaFor`): `# yaml-language-server: $schema=` в начале файла, затем диалект и имя
файла, для `values*.yaml` — `values.schema.json` рядом. Схема по URL не скачивается — в строке
состояния сказано почему. Схема с сервера (чарта, из modeline) — **недоверенный вход**: её `pattern`,
`format` и `patternProperties` отброшены (`untrustedSchema`) — чужая регулярка выполнялась бы в окне.

**3. Проверка** — интерпретатор `@cfworker/json-schema` (ajv компилирует код через `new Function`, CSP
его не пустит). Каждый документ YAML — отдельно, документ k8s — по своему `apiVersion`/`kind`, чужой
вид не проверяется. Ошибка ставится на узел по пути (`yaml`-загрузчик схемы пайплайна), неизвестный
ключ — на сам ключ предупреждением. Из нескольких ошибок места — самая говорящая: «неизвестный ключ»,
только если больше ничего не так (`unevaluatedProperties` в 2020-12 называет неизвестным и известный
ключ, не прошедший свою схему). Тексты — через `t()` по слову схемы (`required`, `type`, `enum`…).

**4. Дополнение из схемы**: ключи, которых ещё нет у отображения, с описанием; после `ключ: ` — значения
`enum`, `const`, `true/false`. Путь — по отступам: набираемая строка ещё не парсится.

**5. Языковой сервер важнее.** Когда для файла запущен yaml-language-server, встроенная проверка уходит.

## Отвергнуто

- **Скачивать схемы по требованию** — сеть в рантайме.
- **ajv** — `new Function` под строгим CSP.
- **Свои схемы Ansible** — несколько тысяч модулей, это работа ansible-lint и его сервера.

## Последствия

- `yamlschema.ts`, чип «Схема: …» в строке состояния. Гейт `editorwork.guard`: схема с сервера —
  через `untrustedSchema`, у каждой схемы — строка в NOTICE.md.
