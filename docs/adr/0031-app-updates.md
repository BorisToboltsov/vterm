# ADR 0031 — История выпусков и собственный помощник обновления

## Контекст

vterm распространяется без Developer ID/нотаризации и Authenticode. Есть MSI/NSIS,
два portable Windows (один с WebView2), universal macOS и три формата Linux. Приложение
работает офлайн и содержит активные SSH-сессии и несохранённые документы нескольких окон.

## Решение

История встроена из канонического CHANGELOG как исходный документ, аналогично инструкции;
элементы интерфейса локализованы RU/EN. Проверка GitHub Latest выполняется только кнопкой.
Подпись канала — собственный Ed25519-ключ, не системный сертификат. CI подписывает манифест
после сборки всех форматов, хостинг остаётся в GitHub Releases.

Помощник — копия уже установленного бинаря в раннем режиме до WebView/single-instance.
Он проверяет пакет, ждёт разрешения установки и завершения приложения, заменяет переносимые
форматы с резервной копией или запускает соответствующий пакетный установщик. macOS получает
подготовку, эквивалентную open-on-mac.sh; ошибки подготовки прекращают установку.

Альтернативы: только ссылка на релиз проще, но оставляет ручную замену; штатный Tauri updater
поддерживает установщики, но не наши standalone portable. Отдельная постоянно работающая
служба не нужна. Собственная реализация криптографии не нужна — используются Node crypto
для подписи и ed25519-dalek для проверки.

## Последствия

Нужны резервная копия ключа, CI secret и испытания реальных переходов на всех платформах.
Предупреждения ОС могут сохраняться. Откат переносимых файлов не откатывает пользовательские
данные; пакетные установки остаются ответственностью установщика. Неатомарное переключение
каталогов при потере питания может потребовать ручного восстановления. Контракты — в
[INVARIANTS](../INVARIANTS.md#обновления-приложения), процедуры — в [INSTALL](../INSTALL.md).
