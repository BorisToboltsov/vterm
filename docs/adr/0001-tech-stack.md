# ADR 0001 — Стек: Tauri 2 + SvelteKit + russh, логика в Rust

**Статус:** принято (Фаза 0–1, подтверждено в Фазе 6).

## Контекст

Нужен кроссплатформенный (macOS + Windows) GUI-клиент SSH/SFTP — лёгкий, нативный,
без Electron-оверхеда, с безопасным доступом к keychain и сети.

## Решение

- **Tauri 2** — нативное окно + Rust-бэкенд (маленький бандл, доступ к ОС).
- **SvelteKit (Svelte 5 runes) + TypeScript + Tailwind v4** — фронтенд как SPA
  (`adapter-static`), рендерится в WebView.
- **russh / russh-sftp** — чистый Rust-SSH (без системного `ssh`); удалённый PTY
  приходит каналом russh, поэтому `portable-pty` не нужен.
- **Инвариант:** вся логика SSH/SFTP/секретов/файлов живёт в Rust; фронтенд ходит
  к ней только через `invoke()` (команды) и каналы событий (`term://…`,
  `sftp://…`, `menu://…`).

## Последствия

- Чёткая граница фронт/бэк; бизнес-логику легко тестировать на Rust-стороне.
- Два дистрибутива на ОС (см. CI); кросс-компиляция между ОС не используется.
- Фронт остаётся презентационным; дублирования логики нет.
