# ADR 0059 — Вынос файла: папка в Проводник обходом сервера, файлы локальной вкладки — как есть

**Статус:** принято (Готовится, после 1.33). Дополняет [ADR 0027](0027-drag-out.md) (вынос файла
обещанием); закрывает долг «Вынос файла (1.14)».

## Контекст

ADR 0027 оставил четыре пункта:

1. На Windows папка не выносится — ни сама, ни в группе с файлами.
2. Файл локальной вкладки системе не отдаётся: «его таскает сам файловый менеджер». Но человек
   уже видит файл в панели vterm — идти за ним в Finder значит искать его второй раз.
3. Файл, который дописывают во время копии в Проводник, копируется той длины, что была в начале.
4. На macOS картинка перетаскивания — системный значок по расширению, а не предпросмотр.

## Решение

### Папка в Проводник — тем, что в ней лежит

Проводник не принимает обещание папки. `FILEGROUPDESCRIPTORW` — плоский список: папка в нём —
запись с атрибутом каталога и без длины, её файлы — записи с путём внутри перетаскивания
(`site\css\a.css`, `feed::windows_path`). Проводник создаёт их по порядку, поэтому папка идёт до
своего содержимого, а пустая папка — тоже запись.

- **Список строится на сервере в момент начала** (`survey` → `flatten`): что каждый выбранный
  элемент сейчас, что в каждой папке, до дна. Длину каждого файла говорит сервер (`seen_of`) —
  Проводнику она нужна до первого чтения. Тот же обход теперь меряет и отдельный файл: прежний
  `measured` ушёл.
- **Целиком или никак.** Ссылка на папку (обход по ней мог бы не кончиться), нечитаемая папка или
  файл, файл без длины, имя, не проходящее `safe_component`, путь внутри длиннее 259 знаков
  (`MAX_PATH` старого API Проводника), больше 500 элементов (`MAX_ITEMS`) — перетаскивание не
  начинается. «Всё, кроме них» было бы неполной копией без слова.
- **Обход останавливается, как только элементов больше предела**: папку на миллион файлов не
  дочитывают до отказа.
- **Отказ называет причину.** `drag_out_begin` отвечает `OutAnswer { taken, why }`; страница
  говорит причину (`declinedMessage`, `dragout.why*`), когда файлы отпустили мимо всех окон, —
  как в 0027 говорит о сессии, которой нет.

Отвергнуто:

- **Скачать папку во временный каталог и отдать `CF_HDROP`** — то же, от чего ушёл 0027:
  скачивание до того, как человек решил, бросит ли и куда.
- **Обходить лениво, после броска.** Проводник читает описание раньше броска, при наведении;
  список должен быть готов, когда начинается `DoDragDrop`.
- **Без предела.** Обход — по запросу на элемент, и жест ждёт его у края окна. Большую папку
  выносят «Скачать» или копией в локальную вкладку.

### Файлы локальной вкладки — как есть

Файл этой машины — не обещание: системе отдаётся сам путь. macOS — `NSURL` файла как писатель
pasteboard, картинка — значок файла из `NSWorkspace`; Windows — `CF_HDROP`, единственный формат
объекта данных, без потоков. Такой бросок принимает любая программа, которая принимает файлы, а не
только понимающая обещание. Источник, как и для файлов сервера, разрешает только копию
(`DROPEFFECT_COPY`, `NSDragOperation::Copy`): перемещение увело бы файл из-под панели, которая его
показывает.

- **Путь пришёл со страницы — бэкенд проверяет его сам** (`local_items`): абсолютный и существует;
  папка это или файл и какой длины — по файловой системе, а не по слову страницы. Пропал — отказ с
  причиной (`gone`).
- Задания в реестре переносов нет: копирует система.

### Не делаем

- **Длина растущего файла.** Проводник копирует ровно ту длину, что объявлена в описании, а
  описание отдаётся до первого чтения. Файл, который дописывают, копируется снимком на момент
  начала: это видно по размеру и сказано в руководстве. Хвост — повторный вынос или «Скачать».
- **Предпросмотр на macOS.** Картинка перетаскивания нужна в начале жеста, а содержимого файла до
  броска нет — предпросмотр значил бы скачивание до решения человека. Значок по расширению — то,
  что система знает без файла.

## Последствия

- На Windows начало перетаскивания папки ждёт обхода сервера — до 500 запросов `metadata`.
- Файл, изменившийся между обходом и чтением, копируется длиной обхода — тот же случай, что
  растущий файл.
- Причина отказа — слово бэкенда (`Declined`), её текст — ключи `dragout.why*` на всех языках.
- Гейт `a_file_leaves_the_app_only_as_a_checked_promise` держит, что файлы этой машины проходят
  `local_items`, а папка — обход и `flatten`, прежде чем перетаскивание начнётся.

## Что не сделано

- **На настоящем приложении не запускалось.** Вынос папки в Проводник и файлов локальной вкладки
  на обеих ОС — в списке проверки владельца. Windows-половину собирает и тестирует только раннер
  CI; раскладки `FILEGROUPDESCRIPTORW` и `DROPFILES` проверены тестами на любой ОС.
