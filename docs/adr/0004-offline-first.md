# ADR 0004 — Офлайн-first: сеть только для исходящего SSH

**Статус:** принято (Фаза 6.2).

## Контекст

vterm — инструмент для доступа к чужим серверам; пользователи ожидают, что сам
клиент не «звонит домой» и работает без интернета.

## Решение

- Никаких runtime-обращений в сеть, кроме **исходящего SSH** к серверам, которые
  пользователь добавил сам.
- Шрифты встроены в бандл (`@fontsource`), без CDN/Google Fonts; нет телеметрии,
  аналитики, авто-апдейта по сети.
- Внешние ссылки (окно About) открываются в системном браузере только по явному
  действию пользователя (`tauri-plugin-opener`).
- Инвариант закреплён тестом-гейтом `src/lib/autonomy.guard.test.ts`, который
  падает, если в исходниках появится `fetch`/WebSocket/CDN/аналитика.

## Последствия

- Предсказуемая приватность и работа в изолированных сетях.
- Любое будущее «сетевое» решение (обновления, синхронизация) требует осознанного
  пересмотра этого ADR и снятия/правки гейта.
- Воспроизводимость сборки: закоммиченные lock-файлы, `--frozen-lockfile`.
