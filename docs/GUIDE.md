| Действие | Сочетание |
|----------|-----------|
| **Командная палитра** | `⌘K` / `Ctrl+K` |
| **Поиск по буферу терминала** | `⌘F` / `Ctrl+Shift+F` |
| Навигация по совпадениям | `Enter` / `Shift+Enter` |
| **История команд** | `Ctrl+R` |
| Копировать выделение | `⌘C` / `Ctrl+Shift+C` |
| Вставить | `⌘V` / `Ctrl+Shift+V` |

| Закрыть диалог / палитру | `Esc` |
| Переключение вкладок | `←` / `→` (по кругу), `Home` / `End` |

## Возможности

### 🔌 Подключение и терминал

Двухпанельное окно: слева сохранённые серверы, справа живой терминал (xterm.js, PTY,
ANSI, авто-resize). Сервер добавляется кнопкой в тулбаре списка, подключается по
**Connect** или двойным кликом.

- **SSH по паролю и ключу** (russh). Без указанного ключа берётся дефолтный из `~/.ssh/` (`id_ed25519` → `id_ecdsa` → `id_rsa`); passphrase для зашифрованных ключей.
- **Proxy / jump host** на каждый сервер: SSH jump (`ssh -J`), SOCKS5, HTTP CONNECT. Секрет прокси — в keychain; на экране ожидания видны подстадии прокси.
- **Вкладки** — несколько соединений (в т.ч. к одному серверу), перетаскивание, статус. `⌘T` / `Ctrl+T` — новая вкладка или локальная консоль.
- **Локальный терминал** (кнопка `+`) — реальный shell машины (forkpty / ConPTY). Выбор оболочки в *Настройки → Терминал* (Windows: cmd / PowerShell / pwsh / свой путь).
- **Синхронный ввод на несколько серверов** — кнопка-broadcast: одна команда уходит на все выбранные сессии, терминалы показываются сеткой или «фокус + список». Отправка на `prod` — с подтверждением; запись при этом групповая.
- **Экран ожидания/ошибки** — честный чек-лист реальных фаз (Соединение → Аутентификация → Сессия); при обрыве замирает на упавшем шаге. Авто-reconnect, таймаут, keepalive.
- **Секреты — в системном keychain**; проверка отпечатка хоста (strict / trust-on-first-use / accept-any).

### 🗂️ Серверы и папки

- Профили — **JSON** в конфиг-каталоге ОС. Запись атомарная (сбой питания не оставит обрезанный список), а повреждённый файл уходит в карантин `*.corrupt-*` с сообщением — не в тихую пустоту.
- **Форма сервера**: псевдоним, host/IP, порт, логин, метод аутентификации, теги. Обязательны псевдоним / host / логин; host и порт валидируются.
- **Пиктограмма** — иконка (~24 глифа) и цвет на профиль, показывается перед именем в списке.
- **Папки** любой вложенности; сервер кладётся в папку перетаскиванием. **Поиск** по alias / host / логину / папке / тегам.
- **Дублирование** сервера (иконка в строке или ⌘K) — сохранённый пароль в копию не переносится.
- **Индикатор подключений** — кружки по числу открытых вкладок сервера (🟢 / 🟡 / 🔴).
- **Клавиатура** в списке: `↑` / `↓` — курсор, `Enter` — подключить / свернуть папку, `Delete` — удалить.

### 📁 SFTP и файлы

Правая панель (разворачивается и подключается кнопкой **Connect** внутри неё).

- Обзор и навигация, создание/удаление папок и пустых файлов, **upload/download**, **drag-and-drop**, прогресс со скоростью и оставшимся временем.
- **Мультивыбор как в ОС** (клик / `Ctrl`-клик / `Shift`-клик); перетаскивание переносит всю выборку; одноимённое в цели пропускается (без перезаписи).
- **Клавиатура**: стрелки — курсор, `Enter`/`→` — открыть/войти, `Space` — отметить, `Cmd/Ctrl+A` — всё, `F2` — переименовать, `X`/`C` → `V` — вырезать/копировать и вставить, `Delete` — удалить, `Cmd/Ctrl+Shift+C` — копировать путь.
- Кнопка-**глаз** — скрытые файлы; кнопка-**терминал** — «следовать за путём терминала».
- **Следование за путём**: на локальной вкладке работает сразу (vterm читает cwd у ОС); на SSH нужен OSC 7 от шелла — приложение предложит вписать команду на сессию. Двустороннее: навигация в панели делает `cd` в терминале.
- **Аудит**: изменяющие операции (`rm`/`mv`/`cp`/`mkdir`/`touch`/`put`/`get`/`save`) пишутся в запись как `[sftp] $ …`, не засоряя живой терминал.

Чтобы следование за путём работало на SSH постоянно, добавьте в `~/.bashrc` на сервере:

```sh
PROMPT_COMMAND='printf "\033]7;file://%s%s\a" "${HOSTNAME:-}" "$PWD"'"${PROMPT_COMMAND:+;$PROMPT_COMMAND}"
```

(`zsh` — через `add-zsh-hook precmd`; `fish` шлёт OSC 7 сам.)

### 🌿 Git

Вкладка **Git** в правом доке — по **текущему пути терминала** (SSH и локально).

- **Тулбар**: ветка со счётчиками ↑/↓, **Pull / Push / Fetch** (сеть — только по кнопке), **Обновить** (локально, без сети).
- **Граф** коммитов (многодорожечный); клик по коммиту — его файлы и диффы; ПКМ — checkout / ветка / тег / cherry-pick / revert / reset / копировать SHA.
- **Изменения** — индекс и рабочее дерево: stage/unstage, откат, удаление, **stash**, чекбоксы. Клик по файлу открывает его в редакторе **инлайн-diff против HEAD**. Коммит-бокс («закоммитить» / «коммит и push»).
- **Ветки** — checkout / create / merge / rebase / rename / delete, stash; тумблер «выполнять checkout в терминале».
- **Прод-защита**: деструктив на `prod`/`production` — с подтверждением. Аудит `[git] $ …`.

### 🐳 Docker

Вкладка **Docker** — контейнеры, образы, сети и тома **на хосте активной вкладки**. Не
установлен / нет прав / демон не запущен — честная подсказка с кнопкой **«Повторить»**.

- **Контейнеры** сгруппированы по compose-проектам: точка состояния, **микрографик CPU** за минуту, доля памяти от лимита, сумма по стеку. Наведение — карточка (порты, CPU/mem/сеть).
- **Действия**: старт/стоп/рестарт в строке, **«Подробнее»** (Overview / Логи / Inspect), ПКМ (shell, логи, inspect, удалить). **Shell в контейнер** — новая вкладка (`docker exec -it`).
- **Образы / сети / тома** — списки с prune; **приватный реестр** — `docker login` (пароль в keychain).
- **Подтверждения** на удаление/стоп/рестарт (любой сервер, на `prod` — красное предупреждение). Обновление раз в `dockerRefreshSec` (по умолчанию 3 с). Аудит `[docker] $ …`.

### ☸️ Kubernetes

Вкладка **Kubernetes** — ресурсы кластера через `kubectl` на хосте активной вкладки.

- **Контекст / namespace** — выбор в тулбаре (kubeconfig не меняется); `-A` — все namespace.
- **Поды** сгруппированы по владельцу (Deployment / StatefulSet / DaemonSet / Job): состояние, `Ready`, рестарты, CPU/mem (при metrics-server), **доля от лимита пода**.
- **Нагрузки** — Deploy/STS/DS/CronJob: масштаб ±, rollout restart. **Сеть** — Services/Ingress, **port-forward** сервиса в терминал. **Кластер** — Nodes (cordon/drain) + Events.
- **Подробнее о поде** (Overview / Логи / Describe / YAML), **shell в под** новой вкладкой (`kubectl exec`).
- Подтверждения на delete / rollout restart / scale-to-0; аудит `[k8s] $ …`. Путь к `kubectl` и `k8sRefreshSec` (5 с) — в настройках.

### 📝 Редактор конфигов

Клик по файлу в SFTP или локальной панели открывает редактор (CodeMirror, 50+ языков, тема
в тон интерфейсу).

- Правка и `Cmd/Ctrl+S` прямо на сервер; **diff перед сохранением**, защита от затирания по SHA-256, индикатор несохранённого. Открыть можно **любой файл** (лимит размера — настройка, 2 МБ).
- **Markdown** — переключатель Код/Превью; картинки рядом с файлом рисуются, бейджи shields.io — локально, картинки из интернета не грузятся; безопасное подмножество HTML отображается.
- **Линт**: YAML/JSON в редакторе + **серверный линт** по SSH (`yamllint` / `shellcheck` / `hadolint` / `nginx -t` / …), валидаторы демонов (`sshd -t`, `visudo -c`, `haproxy -c`, `systemd-analyze verify`) и YAML-семейства (compose / GitHub Actions / Prometheus / Ansible / k8s).
- **sudo-правка** root-конфигов (пароль не сохраняется), опциональный `.bak` рядом с оригиналом.
- **Синхронизация папок** (кнопка в SFTP) — сравнение по SHA-256, dry-run, докачивает только изменённое; ход виден, «Остановить» дописывает текущий файл. **Grep по содержимому**, **шаблоны** конфигов.
- **Windows-панель**: уровень «Этот компьютер» над корнем диска, DOS-атрибуты вместо unix-прав.

### 📈 Мониторинг

- **Статус-бар** снизу: ОС, host/user, график CPU, RAM, свободный диск; подсказки при наведении. Работает на SSH **и локальных** вкладках.
- **Страница мониторинга** (иконка-график в полосе, `⌘/Ctrl+Shift+M` или ⌘K): блок «Система» (Хост / Сеть / Здоровье / Обновления / Оборудование) + health-сводка; секции с графиками (CPU / load / RAM / swap), загрузка по ядрам, ФС + **inodes**, сеть и TCP, **температуры** (lm-sensors), топ-процессы, блок «Дополнительно» (GPU / Docker / SMART / OOM).
- **Пороги** (жёлтый/красный) для метрик — Настройки → Status bar. Данные тянутся только пока страница открыта; на локальной вкладке серверная детализация показана как «—».

### ⏺️ Запись сессий

- **REC** в полосе — запись по вкладке (**asciicast v2**), красный индикатор; старт/стоп из ⌘K. Режимы: полный с таймингами / без таймингов / только команды. Ввод после `password:` маскируется.
- После остановки — заголовок и описание. **Библиотека** (⌘K → «Записи»): поиск, сортировка, группировка (Нет / Сервер / Дата), редактирование, **экспорт** (Markdown-ранбук / команды / транскрипт / `.cast`) с блоком метаданных сессии.
- **Плеер** — play/pause, перемотка, скорость, **полоса активности** (видно, где шла работа). **Автозапись прод-серверов**; пауза при скрытой или простаивающей вкладке.

### 🤖 ИИ-ассистент

**Выключен по умолчанию.** Включается в *Настройки → ИИ-ассистент*: один или несколько
эндпоинтов — локальных (Ollama / LM Studio / vLLM) или облачных (DeepSeek / OpenAI /
Claude). Ключ — в keychain.

- **Добавление по пресету** («Добавить эндпоинт») или «Свой эндпоинт…». **«Проверить подключение»** показывает модели сервера; модель удобно выбирать прямо в чате.
- **Чат** — вкладка «ИИ» в правом доке: ответ стримится, у каждой вкладки свой диалог, генерация идёт в фоне. Виден **ход рассуждения** модели (отдельный блок, в команды не идёт) и **счётчик токенов**. История диалога ограничена настройкой.
- **Спросить прямо оттуда, где смотрите**: выделение в терминале (ПКМ → «Объяснить»), контейнер Docker, под k8s, снимок метрик. Плюс **сообщение коммита** из diff и **план / скрипт / постмортем** из записи сессии.
- **Контекст** (кнопка «Контекст») — выделение / последние строки / весь буфер / запись / метаданные; прикладывается только по нажатию.
- **Приватность**: трафик идёт только на ваш эндпоинт; перед отправкой секреты **маскируются** и показывается **окно согласия** с предпросмотром.
- **Исполнение команд** — под предложенным блоком команды появляются кнопки «Копировать»/«Выполнить»; режимы «только предлагать / подтверждать каждую / диалог» (диалог — **не на** `prod`); опасные команды всегда просят подтверждение; выполненное пишется в запись.
- **Прод-защита**: флаг сервера **«Запретить ИИ»** отключает и контекст, и исполнение.

### 🧰 Утилиты

Панель 🔧 в верхней полосе или ⌘K → «Утилиты». Всё считается **локально, без сети**.

- **SSH-ключи** (Ed25519 / RSA / ECDSA, passphrase, `~/.ssh/`, копирование `.pub`), **known_hosts** (просмотр/удаление), **Base64 / URL / Hex**, **CIDR**, **Timestamp**, **Cron** (+ ближайшие запуски), **генератор паролей и парольных фраз**, **JWT-декодер**.
- **Сетевые** (на хосте активной сессии, не из приложения): **TLS-инспектор** и **HTTP-клиент**. На SSH — удалённо (аудит `[util] $ …`), локально — кнопкой «Выполнить в терминале».

### 🔎 Логи и текст

- **Поиск по всему буферу** (`⌘F` / `Ctrl+Shift+F`) — регистр / слово / regex, счётчик, `Enter` / `Shift+Enter`, копирование совпадения с контекстом.
- **История команд** (`Ctrl+R`) — окно со списком из истории шелла и текущей сессии, живой фильтр; `Enter` вставляет команду в строку (не запускает).
- **Подсветка логов** по regex-правилам (настройки) и **кликабельные ссылки** в выводе.
- **Структурный просмотр** — переключатель **Raw | Table**: авто-определение JSON / logfmt / syslog / nginx / dmesg в единую таблицу (Время / Уровень / Сообщение) с колонками, фильтрами-чипами и авто-скроллом в `tail -f`.

### 🌙 Заставка простоя

После бездействия (нет ни ввода, ни вывода) поверх терминала плавно появляется заставка —
она рисует **копию** экрана и **ничего не вводит** в сессию; любая клавиша или клик её убирают.
*Настройки → Внешний вид → «Заставка»*: эффект и задержка (по умолчанию «Карточка сервера»,
5 мин). Эффекты — Карточка сервера, Матрица, Параллакс из слов, Слабый сигнал. **NO SIGNAL** —
при реальном обрыве соединения. С системным «уменьшить движение» — статичный кадр.

### 🎨 Интерфейс и темы

- **Темы** терминала и UI в реальном времени: фирменные с объёмным фоном (**Deep Well**, Aurora, Glass) + классические (One Dark, Dracula, Nord, Gruvbox, Solarized, Tokyo Night, ретро) и **своя тема**.
- **Правый клик** — контекстные меню на файлах, дереве серверов, вкладках, терминале, git-панели (где своего меню нет — ПКМ не показывает браузерное).
- **Настройки** — двухпанельные, с поиском по всем настройкам; **язык** (EN / RU, по умолчанию из ОС), шрифт / курсор / scrollback / bell; **бэкап** (export/import, без паролей) и **сброс к умолчаниям**.
- **Заметки к серверу** (Markdown) — кнопка в верхней полосе, автосохранение, точка-индикатор; попадают в бэкап.
- **Показать пароль** — глазик в любом поле секрета (виден только набранный сейчас текст; сохранённый секрет не подставляется).
- **Панели** тянутся мышью и сворачиваются; масштаб шрифта — щипок на тачпаде / `Ctrl+колесо`.

### 🔐 Безопасность и приватность

- **Полностью офлайн**, кроме исходящего SSH к вашим серверам (и, если включите ИИ, запросов к вашему эндпоинту) — закреплено тест-гейтами.
- Секреты — только в **системном keychain** (`zeroize`), не в файлах и не в бэкапе. Строгий CSP, минимальные capabilities, SAST-гейты (`cargo audit`/`deny`, `pnpm audit`, Semgrep, Trivy). Полная модель — в [SECURITY.md](../SECURITY.md).

### Командная палитра ⌘K

`⌘K` / `Ctrl+K` — поиск по **серверам** (подключение), **папкам**, **действиям** и
**настройкам**. `↑` / `↓` — выбор, `Enter` — выполнить, `Esc` — закрыть.

### Доступность

Видимое кольцо фокуса, фокус-трап и `Esc` в диалогах, роуминг-навигация по вкладкам (ARIA
*tablist*), дерево серверов `role="tree"`. Анимации уважают системное «уменьшить движение».
На macOS для попадания `Tab` на кнопки включите *Системные настройки → Клавиатура → Навигация
с помощью клавиатуры*.
