# Changelog — vterm

Что менялось по версиям, **от новых к старым**. Схема версий — `<major>.<фаза>.<фикс>`; карта фаз —
в [docs/ROADMAP.md](docs/ROADMAP.md), контракты — в [docs/INVARIANTS.md](docs/INVARIANTS.md),
обоснования решений — в [docs/adr/](docs/adr/).

## 🔧 Не выпущено (готовится к v1.0.0)

- **CI на GitHub — раньше его не было вовсе.** До этого в `.github/` лежал только
  `release.yml`, и пуш тега собирал и публиковал три бандла, не прогнав ни одного теста.
  Появились `ci.yml` (типы, тесты с покрытием, production-сборка; `fmt`/`clippy`/`test`
  на Linux + **Windows** + macOS; `cargo audit`/`cargo deny`/`pnpm audit` жёстко),
  `codeql.yml`, `security.yml` и `nightly.yml`.
- **Первая находка windows-раннера:** тесты `localenv::combine_paths_*` держали PATH-строки
  с зашитым `:`, тогда как сам `combine_paths` разбирает их платформенным
  `std::env::split_paths` (`;` на Windows). Код был прав, тесты — нет; фикстуры теперь
  строятся через `join_paths`. До появления раннера это не мог поймать никто.
- **Релиз стоит под гейтом CI.** `release.yml` вызывает `ci.yml` целиком через
  `workflow_call`, матрица сборки — под `needs: verify`. Копии шагов нет: она разошлась бы
  с оригиналом на первой правке.
- **Версия сведена в один источник.** Правится только `package.json` командой
  `pnpm version:set X.Y.Z`; `tauri.conf.json` берёт её ссылкой `"../package.json"`,
  `Cargo.toml`/`Cargo.lock` синхронизирует `scripts/set-version.mjs`. CI читает версию
  оттуда же. Новый гейт `version.guard`.
- **Цепочка поставки CI.** Экшены запинены по коммит-SHA с комментарием версии (изменяемый
  тег переписывается владельцем, а `tauri-action` работает с токеном на запись в релизы),
  обновляет их Dependabot; имя тега уехало из `run:` в `env` (подстановка `${{ }}` в шелл-
  строку — исполнение чужого значения); добавлены CodeQL по `javascript-typescript`/`rust`/
  `actions` и SARIF-витрина для Semgrep, Trivy и zizmor.
- **Целостность релиза.** К ассетам добавлены `SHA256SUMS`, SLSA-provenance
  (`gh attestation verify`) и SBOM в CycloneDX — единственное, что можно дать вместо
  подписи, пока её нет. Отправка ассетов во VirusTotal — opt-in по секрету `VT_API_KEY`.
- **Фаззинг недоверенного входа.** `fast-check` по рендеру markdown, парсерам логов,
  бейджам и маскированию секретов; `proptest` по кодировкам. Свойства проверяются разбором
  DOM, а не регулярками. Ночью — на два порядка глубже. Там же ожили E2E и живые
  SFTP-тесты, которые в GitLab-пайплайне стояли ручными и не запускались.
- **Ассеты релиза в GitHub Actions.** В релиз доливаются `open-on-mac.sh` рядом с `.dmg` и
  `vterm-portable-<версия>-x86_64.exe`; тело релиза перечисляет, что качать под какую ОС.
  Гейт `releaseassets` проверяет оба шага.
- **Тулчейн CI выровнен с машиной разработки:** pnpm 10 → 11 (тот мажор, что породил лок-файл
  и понимает `pnpm-workspace.yaml`), Node 20 → 22 — pnpm 11 требует Node ≥ 22.13 и на Node 20
  падает первым же вызовом, разом на всех трёх ОС. Пара «pnpm ↔ Node» закреплена гейтом.
- **Экшены релиза переведены на рантайм Node 24** (`checkout@v7`, `setup-node@v7`,
  `pnpm/action-setup@v6`) — GitHub исполнял прежние `@v4` на Node 24 принудительно и предупреждал,
  что подпорку уберут. Гейт держит и этот пол — он отдельный от `node-version` (рантайм экшенов,
  а не Node проекта).
- **Ссылка на GitHub в окне «О программе»** — рядом с Telegram и почтой; открывается во внешнем
  браузере, как остальные ссылки.
- **Ревизия документации: 10 600 строк убрано, жанры разведены.** INSTALL начинается с готовой
  сборки, разбор ошибок переехал в TROUBLESHOOTING; INVARIANTS дедуплицирован и вобрал контракты
  подсистем; ARCHITECTURE переписан под архитектуру (997 → 182); DESIGN стал справочником;
  ROADMAP — картой фаз (3611 → 129); CHANGELOG — списком изменений (3031 → 624); TESTS — картой
  набора вместо перечня тестов (1652 → 196). Ключевые решения оформлены шестью новыми ADR.
  В CLAUDE.md добавлена «Карта документации» — что в какой файл писать и чего туда не писать;
  README получил карту вопросов, CONTRIBUTING приведён в соответствие с кодом, в SECURITY
  описана защита от недоверенного markdown.

## v0.44.10 — Светлые темы: текст больше не пропадает

- `text-white` заменён на тематический `text-text` по всему приложению (385 мест в ~70
  компонентах) — на светлых темах текст больше не белый по кремовому.
- Белый оставлен только на сплошных насыщенных кнопках; кольцо выбора цвета сервера —
  `ring-accent` вместо `ring-white`.
- Гейт запрета палитровых классов расширен на безчисловые `text-white`/`text-black`.

## v0.44.9 — Команды переезжают к своим модулям

- 16 самодостаточных команд (локальные файлы, генерация ключей, known_hosts) переехали из
  `lib.rs` в свои модули. Имена команд не менялись.
- Команды поверх общего состояния сессий осознанно оставлены единым мостом.

## v0.44.8 — Файловые панели — один компонент

- SFTP-панель и локальная панель объединены в общий `FileBrowser` с адаптером транспорта; две
  панели стали тонкими обёртками. Убрано ~720 строк дублирования, поведение не менялось.
- Общая чистая логика вынесена в тестируемый модуль.

## v0.44.7 — Обновление зависимостей перед релизом

- 89 Rust-зависимостей и фронт-стек обновлены в рамках semver; `russh` оставлен на прежней линии.
- `plist 1.9 → 1.10` подтянул `quick-xml 0.41` — две DoS-уязвимости разбора XML устранены, а не
  подавлены исключением.
- Остаётся принятый риск: тайминговая уязвимость в `rsa` без исправленной версии (дефолт —
  ed25519).

## v0.44.6 — HTML-разметка в превью markdown

- HTML в `.md` отображается, а не выводится текстом: `<div align="center">`, `<sub>`/`<sup>`,
  `<kbd>`, таблицы, `<details>`.
- Разметка проходит строгий белый список — скрипты, обработчики событий, стили и `<iframe>`
  вырезаются. Включено только в превью редактора; ответы ИИ и заметки экранируются полностью.

## v0.44.5 — Бейджи в README рисуются без интернета

- Статические бейджи shields.io рисуются самим приложением из адреса, без обращения в сеть.
- Динамические бейджи (звёзды GitHub, версия npm) остаются заглушкой.
- Пояснение «картинки из интернета не загружаются» появляется только когда что-то действительно
  не отрисовалось.

## v0.44.4 — Картинки в превью markdown

- Синтаксис `![подпись](картинка.png)` распознаётся; файл рядом с документом подтягивается тем
  же транспортом (SFTP или диск), включая `../`, абсолютные и Windows-пути.
- Картинки из интернета не загружаются — вместо битой картинки заглушка с подписью и строка
  объяснения.
- Починена разметка бейджа-со-ссылкой `[![…](…)](…)`.

## v0.44.3 — Ссылка в ответе ИИ больше не может ничего выполнить

- Ссылки в markdown проверяются по схеме: `javascript:` и подобные отклоняются и рисуются
  текстом. Раньше такая ссылка была рабочей в ответах ИИ, планах, заметках и любом `.md`,
  открытом на сервере.
- Любая ссылка открывается во внешнем браузере — окно приложения больше не переходит никуда.
- Проверка встроена в тесты и не даёт добавить новое место показа markdown без защиты.

## v0.44.2 — Закрытая вкладка уходит целиком

- Удаление сервера с открытыми вкладками больше не оставляет в памяти тексты открытых файлов,
  переписку с ИИ и служебные кэши; то же при повторном вводе пароля после отказа.
- Из набора синхронной рассылки убирается идентификатор закрытой сессии.
- Путь закрытия вкладки теперь один и закреплён проверкой.

## v0.44.1 — Список серверов переживает сбой

- Файлы профилей, папок и known_hosts пишутся атомарно (временный файл → сброс на диск →
  замена): обрыв питания больше не оставляет обрезанный список.
- Повреждённый файл переносится в `servers.json.corrupt-<метка>` до первой записи, приложение
  сообщает куда; сообщение не исчезает по таймеру.
- Отдельное сообщение на случай, когда спасти файл не удалось.
- Отсутствующий файл при первом запуске по-прежнему молчит.

## v0.44.0 — Шкала кеглей

- Размеры шрифта переведены на шкалу из четырёх ступеней (328 литералов в 62 файлах); новое

- Заголовки-рубрики выровнены на один кегль. Сами размеры не изменились — это переименование.

## v0.43.0 — Потолки нагрузки в Docker/k8s, читаемые статусы, видимый фокус

- У чисел нагрузки появился знаменатель — доля от лимита пода или контейнера с цветом по мере

- Клавиатурный фокус обведён явно на всех кнопках, вкладках, списках и полях.
- Уведомления выезжают и уходят плавно, оставшиеся съезжают на освободившееся место.

## v0.42.0 — Живость интерфейса: движение, скорость переноса, форма нагрузки

- Диалоги появляются за 120 мс, закрываются мгновенно; вкладки правого дока переключаются
  кроссфейдом.
- Системная настройка «уменьшить движение» теперь гасит **все** переходы; добавить анимацию в
  обход неё нельзя — прогон падает.
- В переносах SFTP показываются скорость и оставшееся время (по последним секундам); пока данных
  мало — «измеряю…», у застрявшего переноса время не показывается.
- У записей появилась полоса активности — видно, где шла работа.
- У контейнеров и подов — микрографик CPU за минуту; пропущенное измерение оставляет разрыв, а
  не ноль.

## v0.39.6 — Сохранение по SFTP перестало обнулять файлы + вставка CRLF

- Фикс: сохранение по SFTP уничтожало файл (ноль байт при зелёном тосте). Шаг сохранения прав
  строил `FileAttributes` из `..Default::default()`, где `size: Some(0)` — сервер делал
  `truncate`. Исправлено конструктором `chmod_attrs`; то же место в sudo-сохранении.
- Добавлены живые SFTP-тесты против настоящего сервера — чистые тесты были зелёными, пока
  редактор уничтожал каждый файл.
- Фикс: копия `.bak` создавалась с правами по умолчанию — конфиг `0600` резервировался как
  `0644`. Права оригинала переносятся на копию.
- Провал создания `.bak` отменяет сохранение (`backup-failed`) до касания файла.
- Фикс: многострочная вставка в редактор не работала на Windows (CRLF-нормализация уводила
  каретку за конец документа, `RangeError` до применения). Гейт `clipboardpaste`.

## v0.39.5 — Команды выполняются на Windows + два фикса

- Фикс: команда вставлялась в терминал, но не выполнялась на Windows — во все восемь мест, где
  vterm пишет в PTY, уходил LF вместо CR. Терминатор вынесен в `terminput.ts`, многострочные
  блоки шлются построчно. Гейт `terminput`.
- Фикс: `warning: unused import: is_read_only` при сборке на Windows.
- Текст про температуру на Windows сокращён до одной строки.

## v0.39.4 — Двустороннее следование на локальных вкладках

- Локальная панель ведёт терминал за собой: двойной клик по папке, Enter, подъём по `..`,
  ввод в строке пути и пункт меню «Перейти сюда в терминале». Только при включённом тумблере и
  только на действиях пользователя.
- Команда `cd` строится под реально запущенную оболочку: `cmd.exe` (нужен `/d`, `'` не кавычки),
  PowerShell (`-LiteralPath`, удвоение кавычек), POSIX. Вид оболочки фиксируется на сессию.
- Пустой путь и путь с переводом строки отвергаются; уровень «Этот компьютер» не зеркалится.

## v0.39.3 — «Следовать за терминалом» работает без настройки shell

- На локальных вкладках cwd читается у ОС по pid оболочки (`/proc`, `proc_pidinfo`, PEB) — без
  настройки shell и без новых зависимостей; ловит и `cd` внутри скрипта.
- Диалог с предложением вписать сниппет показывается только на SSH-вкладках.
- Поддержан OSC 9;9 (windows-диалект): снимаются кавычки профилей PowerShell, принимаются
  windows-, POSIX-, UNC-пути и `file://`; прочие подтипы OSC 9 игнорируются.
- OSC 7/9;9 остаются подключены параллельно опросу — шелл, который сообщает каталог сам,
  обновляет панель мгновенно.

## v0.39.2 — Редактируемая строка пути в файловых панелях

- Клик по строке пути превращает её в поле ввода: Enter — переход, Escape и потеря фокуса —
  отмена. Одинаково в локальной панели и в SFTP.
- Ввод нормализуется: снимаются кавычки «Копировать как путь», раскрывается `~`, срезается
